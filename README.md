# Weighbridge 120T — Web Simulator

نسخة ويب أولية مفتوحة المصدر لمحاكاة وإدارة ميزان شاحنات بسعة تصميمية 120 طن.

## تشغيل المشروع

لا يحتاج المشروع إلى تثبيت حزم أو إعداد خادم:

1. نزّل المستودع أو افتحه محليًا.
2. افتح `index.html` في متصفح حديث.
3. استخدم لوحة محاكاة الوزن لتغيير القراءة.
4. أدخل رقم السيارة، وسجّل الوزنة الأولى ثم غيّر القراءة وسجّل الوزنة الثانية.

يمكن أيضًا تشغيله عبر أي خادم ملفات ثابتة، مثل إضافة Live Server في VS Code.

## الموجود في الإصدار الأول

- لوحة تشغيل عربية RTL ومتجاوبة مع الهاتف.
- محاكي قراءة من 0 إلى 120,000 كجم.
- حالة ثبات القراءة ومنع الالتقاط أثناء عدم الاستقرار.
- دورة وزنتين وحساب صافي الحمولة.
- سجل تذاكر محفوظ في Local Storage.
- تذكرة قابلة للطباعة.
- تصدير CSV.
- ملخص السيارات والعملاء والتقارير.
- شاشات توضيحية لخيارات RS232 وUSB وEthernet.

## حدود مهمة

- هذه نسخة محاكاة وليست نظام وزن معتمدًا.
- لا يوجد اتصال فعلي بمؤشر وزن في هذا الإصدار.
- صفحة الويب العادية لا تستطيع فتح منافذ COM أو USB Serial أو TCP الخام بشكل عام. الربط الفعلي يتطلب بروتوكول مؤشر الوزن وخدمة محلية (Bridge) أو تطبيق سطح مكتب.
- التخزين الحالي محلي داخل المتصفح؛ مسح بيانات المتصفح قد يؤدي إلى فقدان السجلات. لا تستخدمه كسجل تجاري معتمد.
- يلزم اختبار ميداني ومعايرة معتمدة قبل استخدام أي قراءة لأغراض تجارية أو قانونية.

## التقنية

HTML, CSS, Vanilla JavaScript — بدون اعتماديات خارجية في التشغيل (الخط Cairo يُحمّل من Google Fonts عند توفر الإنترنت، مع خطوط بديلة).
