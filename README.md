# Weighbridge Simulator — Web + Windows

نظام إدارة ومحاكاة ميزان البسكول بإصدارين يشتركان في نفس واجهة التشغيل ومنطق تسجيل الوزن:

1. **Web Edition:** يعمل من المتصفح، ويمكن نشره على GitHub Pages.
2. **Windows Edition:** تطبيق سطح مكتب مستقل يعمل محليًا دون إنترنت بعد تثبيته.

## نسخة الويب

- افتح الموقع المنشور أو افتح `index.html` من خلال خادم ملفات محلي.
- محاكاة وزن من 0 إلى 120,000 كجم.
- دورة وزن أول وثانٍ وحساب صافي الحمولة.
- سجل تذاكر وتقارير وطباعة وتصدير CSV / Excel.
- حفظ محلي داخل المتصفح.
- Web Serial متاح في المتصفحات الداعمة وعبر سياق آمن.

## نسخة Windows — Offline

تطبيق Electron مع SQLite ومحركات اتصال محلية:

- لا يحتاج اتصال إنترنت عند التشغيل.
- قاعدة البيانات تحفظ في مجلد بيانات المستخدم الخاص بالتطبيق، داخل ملف `weighbridge.sqlite`.
- حفظ سجلات الوزن والإعدادات محليًا، وتظل البيانات بعد إغلاق التطبيق وإعادة تشغيل الكمبيوتر.
- منافذ COM وUSB-to-Serial عبر مكتبة SerialPort الأصلية.
- إعدادات Serial موسعة: Baud Rate قابل للإدخال، وData Bits وParity (None/Even/Odd/Mark/Space) وStop Bits وRTS/CTS.
- تجربة تلقائية لمجموعة من سرعات الاتصال وإعدادات Parity الشائعة، مع تثبيت الإعداد الذي يستقبل قراءة رقمية.
- بروفايلات إعداد أولية لعدد من مؤشرات الوزن، مع وضع Generic قابل للتخصيص.
- اتصال TCP مباشر بمؤشر الوزن على الشبكة المحلية (LAN) دون إنترنت.
- تصدير Excel يعمل من نسخة مكتبة XLSX المحلية المرفقة مع التطبيق.
- التثبيت لا يتطلب متصفحًا أو خادمًا محليًا أو خدمة سحابية.

### بناء نسخة Windows

المتطلبات لبناء البرنامج فقط: Windows، Node.js 22 أو أحدث، واتصال إنترنت أثناء تنزيل حزم البناء أول مرة. **البرنامج الناتج لا يحتاج إنترنت للتشغيل.**

```bash
npm install
npm run dist:win
```

النواتج داخل مجلد `release/`:
- مثبت Windows بصيغة NSIS.
- نسخة Portable بصيغة EXE.

يمكن أيضًا تشغيل البناء من GitHub Actions عبر:
**Actions → Build Windows Desktop App → Run workflow**.
سيتم رفع ملفي EXE كـ Artifact باسم `Weighbridge-Simulator-Windows`.

## التخزين والبيانات

- Web Edition: Local Storage في المتصفح.
- Windows Edition: SQLite محلية في جهاز المستخدم.
- لا توجد مزامنة سحابية أو إرسال تلقائي للبيانات.
- احتفظ بنسخة احتياطية من ملف `weighbridge.sqlite` عند الحاجة لنقل السجلات إلى جهاز آخر.

## البروتوكولات والتوافق

البرنامج يوفّر محرك قراءة قابلًا للتوسعة لرسائل ASCII وCR/LF وSTX/ETX وتدفق البيانات، مع إعدادات اتصال Serial وTCP وتجربة تلقائية لإعدادات Serial الشائعة. ملفات التعريف الظاهرة في الواجهة هي إعدادات/أنماط أولية وليست شهادة بأن كل موديلات Rice Lake أو كل بروتوكول مغلق مدعوم بالفعل.

دعم كل مؤشر يتطلب اختبار بروتوكوله الفعلي: صيغة الإطار، أوامر الطلب، وحدات الوزن، حالات الاستقرار/الحركة، ورسائل الخطأ. بعض الأجهزة تستخدم بروتوكولات ثنائية أو أوامر خاصة أو USB HID؛ تُضاف لها Drivers/Parsers مستقلة عند توفر دليل الشركة أو عينة اتصال. اتصال TCP الحالي هو TCP client، وليس ماسحًا تلقائيًا لكل أجهزة الشبكة أو دعمًا عامًا لكل UDP.
